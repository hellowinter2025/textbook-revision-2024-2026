# 高中教材改版对照（2024 版 ⇄ 2026 版）

把 **2024 版** 与 **2026 版** 高中教材逐字比对，把「改动了的地方」做成左右对照的 PDF。

左栏放 2024 版原页、右栏放 2026 版原页，两页都是**原尺寸矢量页**（不是截图，可以放大、可以选中复制文字）；两版之间有差异的文字用**浅红色框**标出来。

---

## 怎么看

| 图上元素 | 含义 |
| --- | --- |
| 浅红色框 | 该处文字在两版之间存在差异 |
| 右侧页边的红色编号 | 与它同一水平位置的那个红框的序号；左右两栏各自贴在自己那一页的右边 |
| 红色竖线 | 纯新增／纯删除时，在另一侧标出「插入／删除发生在哪个位置」 |
| 页头一行行小字 | 本组改动清单（`"旧文" → "新文"`） |

其他约定：

- **纯新增／纯删除**的改动：没有内容的那一栏显示「位置参考页」——改动在另一版中对应的那一页，不会留空。
- **整篇删除**的课文：只作一页说明（课文名、原页码、字数），**不再附原文**。
- **整篇新增**的课文：逐页附上 2026 版原文（居中呈现，不加标注）。
- 同一页上完全相同的改动会合并显示 `×N`（例如括号统一 `﹝ → 〔` 在某一页出现 29 次）。
- PDF 带两级书签：一级＝分册，二级＝改动组。

## 结构化数据（`json/`）

不想翻 PDF 的话，改动清单也导成了 JSON，字段含义见 [`json/index.json`](json/index.json) 里的 `fields`。

| 文件 | 内容 |
| --- | --- |
| `json/index.json` | 总索引：各科册数 / 改动组 / 改动处数 + 字段说明 |
| `json/<科目·版本>.json` | 每科一份，含各册各改动组（`group` 编号与 PDF 里的「改动组 N / M」一致） |
| `json/all.json` | 全部 13 套合成一份，方便脚本一把读 |

```jsonc
{
  "subject": "化学·苏教版",
  "totals": { "books": 5, "groups": 56, "changes": 108 },
  "books": [{
    "name": "必修 第一册",
    "old_pdf": "2024/5-化学/普通高中教科书·化学必修 第一册.pdf",
    "new_pdf": "2026_去水印/化学/苏教版/普通高中教科书·化学必修 第一册.pdf",
    "groups": 9, "changes": 27,
    "items": [{
      "group": 5,
      "old_pages": [53], "new_pages": [53],
      "changes": [{
        "no": 1, "type": "修改",
        "old": "ma", "new": "-Man",
        "old_pages": [53], "new_pages": [53],
        "old_ranges": { "53": [[42, 44]] },      // 第 53 页字符 42–44
        "new_ranges": { "53": [[42, 46]] },
        "context": "，美国科学家盖尔曼（M.Gell⟦⟧n）提出质子、中子由更小的夸克构"
      }]
    }]
  }]
}
```

`changes[].count`（无此字段即为 1）对应 PDF 里合并显示的 `×N`；`old_anchor` / `new_anchor` 是纯新增／纯删除时画红竖线的位置。

## 比对脚本（`scripts/`）

完整可复现的脚本集，纯 Python，用法与算法要点见 [`scripts/README.md`](scripts/README.md)。

| 脚本 | 作用 |
| --- | --- |
| `pipe2.py` | **核心**：`one` / `buildone` / `merge` 三个阶段；科目配置表 `TASKS` 在文件顶部 |
| `runjobs.py` | 并行调度（按册拆独立子进程，`diff` / `build` / `status`） |
| `dewm.py` | 去 Acrobat 水印（三类形态） |
| `export_json.py` | 导出本目录的 JSON |
| `audit2.py` / `audit_run.py` / `mkdiag3.py` / `verifyfast.py` | 逐组审计与版面核查 |
| `gen_overview.py` | 生成 `docs/改版对照总览.md` |

```bash
pip install pymupdf numpy requests pysocks
py scripts/runjobs.py diff 12     # 逐册算差异（务必后台跑；68 册 16 核约 22 分钟）
py scripts/runjobs.py build 12    # 生成对照页 + 按科目合并
py scripts/export_json.py json    # 导出 JSON
```

> 脚本默认的数据目录是 `2024/`、`2026_去水印/`、`对比结果/`、`_preview/`（均相对项目根目录），需要按自己的目录改 `pipe2.py` 顶部的 `TASKS`。

## 比对是怎么做的

1. **逐字对齐**：把整本书的字符按页串起来（去掉空白，书眉页码单独掩码），用 `difflib.SequenceMatcher` 做字符级比对。不做按页对齐——2026 版有整段增删，页码会错位。
2. **掩码书眉页码**：某一行如果在 35% 以上的页面上都出现在同一个纵向位置，就判定为书眉／页码并屏蔽掉，避免因为换页造成成片的假差异。新旧两版取掩码位置的并集，保证两侧对称；连续掩码折叠成一个字符，避免两侧书眉长度不同造成假差异。
3. **排除图/表内部文字**（这是最难的一类噪声）：教材改版常把整张图从位图改成矢量重排（例：2026 版化学把「元素周期表」和附录的元素数据表做成了可选中文字，2024 版还是图片）。这类文字在两版之间抽取顺序、字号、内容都不同，会造出「一整句正文 ⇄ 表格里几个字」这种离谱配对。四道过滤：① 按册自动定阈值（正文体字号 × 0.78），丢弃图内小字；② 丢弃行内字符 x 坐标回跳（抽取顺序与阅读顺序不一致）的短行；③ 丢弃「中文只是零散单字、其余全是数字符号」的标签串；④ 一侧是完整句子、另一侧是不成句的孤立碎片时，只保留句子那一侧。
4. **剔除伪差异**：① 掩码后两侧都不剩真实文字的；② 同一段文字在一处删除、另一处新增（整段搬家）；③ 同一组内新旧字符集合完全一致的（如版权页竖排改横排）；④ 子集字体缺 ToUnicode 表导致抽出来是印地／阿拉伯乱码的。
5. **生成 PDF**：用 PyMuPDF 的 `show_pdf_page` 把原页**矢量嵌入**（不是栅格化截图），再叠加红框、编号、竖线等标注。
6. **自检**：逐页脚本核查左右两栏是否都有内容、每条改动是否都有标注、编号是否都落在页边；再逐「改动组」算左右两页的文本相似度，把相似度过低的组挑出来人工复核（剩下的都是 2026 版整段重写导致的，页面本身是对应的）。

产出统计：字符级比对约 **1.8 亿字符**（68 册 / 1031 页对照页）。
